# Controle de Estoque

Aplicativo Windows da Troven para conferir pedidos e saldos de estoque.

Os instaladores ficam em Releases. Este repositório distribui o programa; não contém planilhas de clientes.

## Atualizações

Instale a versão 1.6.0 uma vez. O aplicativo consulta os Releases públicos ao abrir e a cada seis horas, confere o SHA-256 e instala novas versões após concluir a consulta em andamento.

A pasta de trabalho é Estoque, na área de trabalho. Atualizações preservam seus arquivos.
